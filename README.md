# MSZ 图片音乐 v1.0

把 MIDI 变成一张图，把这张图放回来就是音乐。

- 模式一：导入 `.mid` → 自动生成一张「钢琴卷帘图」PNG，整个 MIDI 原文件无损藏在这张图里。
- 模式二：导入那张 PNG → 自动把 MIDI 取出来并**立即播放**。

一个文件，只依赖 Python 标准库（不装 mido / Pillow / pygame / numpy）。

## 怎么运行

1. 装 Python 3.8 或更高版本（Windows 上勾选 Add Python to PATH）。
2. 双击 `启动.bat`。
   或者命令行：`python "MSZ图片音乐.py"`。

只想要图片、不想开界面：

```
python "MSZ图片音乐.py" --make 歌.mid 图片.png
python "MSZ图片音乐.py" --info 图片.png
```

## 界面

- 顶部两个模式按钮，切换时下面的按钮文字跟着变。
- `导入文件`：模式一下选 MIDI，模式二下选图片。
- `播放 / 停止`：模式二导入后自动开播，也可以手动重播；模式一生成图片后也能直接试听。
- `导出 MIDI`：从图片里把 MIDI 存成 `.mid`，可以直接拿去给别的播放器。
- `打开所在文件夹`：跳到图片所在目录。
- 播放时图片上有一条竖着的播放头在走，能直观看到当前播到哪一小节。

## 图里到底存了什么

生成图片时做两件事：

1. **PNG 私有数据块 `msZd`**：原封不动塞入整个 `.mid` 文件的字节，再加长度和 CRC32 校验。这是主通道，无损。
2. **像素最低位（LSB）备份**：把同样的字节按位铺到 RGB 每个通道的最低位，肉眼看不出来。主通道被别的软件丢掉时（比如某些工具重存 PNG 会删掉未知块），还能从像素里捞回来。

图片底部那条像条码的东西，就是把藏进去的字节按值画成的高度条——数据看得见。

## 限制（先知道，省得以为坏了）

- **只认 PNG**。JPG 是有损压缩，会把最低位改掉，数据必坏。截图另存、缩放、转格式都会破坏数据。
- **图片不要缩放**。像素被重排后 LSB 备份失效；如果 PNG 的私有块还在，仍能读。
- 一首 MIDI 的容量上限约等于「宽 × 高 × 3 ÷ 8」字节，1440 宽的图通常够放几十分钟的曲子；曲子过大时程序会自动加高图片，超过 4096 像素就提示太大。
- **播放声音走 Windows 系统 MIDI 合成器**（Microsoft GS Wavetable Synth），Windows 10/11 默认就有，不用装音源。在 Linux/macOS 上能看画面但没有声音。
- 音量、音色由系统默认 MIDI 设备决定，程序只发音符，不改混音设置。

## 支持哪些 MIDI

- 格式 0 / 格式 1，多轨、变速度（tempo 变化）、变速拍号、running status、SMPTE 时间基准都能读。
- 只播放音符与音色（program change）；控制器、弯音、歌词等信息会随原文件一起藏进图片，导出后完整保留原文件。
- 音轨名可以是中文（UTF-8 / GBK 都能解）。

## 常见问题

**导入图片说「这张图里没有音乐数据」**
说明这张图不是本程序生成的，或者被 JPG 化 / 缩放 / 截图过。回到模式一，用原始 MIDI 重新生成一张。

**没有声音**
系统缺 MIDI 合成器。开始菜单搜「声音」，确认有默认播放设备；或在「设备管理器 → 声音」里确认 GS Wavetable 存在。画面和播放头仍会正常走。

**图片生成很慢**
一首几分钟的曲子大约 0.3–2 秒，取决于音符数量；几千个音符的曲子也就一两秒。
